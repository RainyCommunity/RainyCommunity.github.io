STORY REPORT

การแจ้งใบ STORY

กติกาการแจ้งใบและค่าปรับจากสตอรี่ วิธีส่งหลักฐาน ข้อยกเว้น และอัตราโทษใบ

FOREIGN PLAYER

ผู้เล่นต่างประเทศ

  • ผู้เล่นต่างประเทศสามารถเข้าร่วมการไฟต์สตอรี่ได้ตามปกติ แต่ต้องลงทะเบียนและสวมใส่ ปลอกแขนผู้เล่นต่างประเทศ ทุกครั้งก่อนเข้าร่วมให้ชัดเจน
  • บทลงโทษ: ปรับ 1,000,000 IC และ บำเพ็ญ 200 ไม้ ต่อคน
REPORT TIME

ช่วงเวลาที่สามารถแจ้งใบ

  • การแจ้งใบหรือค่าปรับจากสตอรี่ สามารถดำเนินการได้หลังจาก สตอรี่สิ้นสุดลงเท่านั้น
  • ยกเว้นกรณีตรวจพบ MG / ตัวปิง / ตัวแปลก / สตรีมสไนป์ / โปรแกรมช่วยเล่น / Multi ID
  • การแจ้งใบเป็นค่าปรับจากสตอรี่ สามารถดำเนินการได้หลังจากสตอรี่สิ้นสุดลงเท่านั้น
EVIDENCE

วิธีการส่งหลักฐาน

  • ให้รวบรวม ข้อความที่พูดในคลิป มาพิมพ์เป็นประโยคให้ครบถ้วน
  • ต้องระบุ ช่วงเวลา ที่เกิดเหตุอย่างชัดเจน เช่น นาที / วินาที เพื่อให้สภาตรวจสอบได้ตรงจุด
  • สภาจะพิจารณาตามข้อความที่ถูกพิมพ์ส่งมาเท่านั้น และอ้างอิงตามช่วงเวลาที่ระบุในคลิปว่าอยู่ในเหตุการณ์จริงหรือไม่
  • หากตรงตามหลักฐานและอยู่ในช่วงเวลาที่ถูกต้อง สภาจะดำเนินการลงโทษตามความผิด เช่น การออกใบเตือนหรือค่าปรับตามกฎของประเทศต่อไป
CHEAT CASE

กรณีโปรแกรมช่วยเล่นและข้อยกเว้น

  • หากตรวจพบการกระทำผิดเกี่ยวกับโปรแกรมช่วยเล่น ยกเว้นกรณี MG / ตัวปิง / ตัวแปลก / สตรีมสไนป์ / Multi ID
  • สภาจะตัดสินให้ฝ่ายที่กระทำผิด ปรับแพ้สตอรี่ ทันที และจะทวงสินเดิมพันคืน พร้อมประกาศสกอร์ใหม่
  • หากทั้งสองฝ่ายมีความผิดในลักษณะดังกล่าวพร้อมกัน สภาจะตัดสินให้ผลเป็น เสมอ และจะไม่มีการคืนสินเดิมพันหรือผลประโยชน์ใด ๆ ทั้งสิ้น โดยรวมในข้อ 1
PENALTY CARD

อัตราโทษใบ

  • บทลงโทษ: ใบเหลือง = 1M / ใบส้ม = 2M / ใบแดง = 3M
  • หากทั้ง 2 ฝั่งต้องการแจ้งใบ ต้องตกลงกับทางสภาก่อนในเรื่องการแจ้งใบ
  • ถ้ามีฝั่งใดฝั่งหนึ่งเลือกแจ้งเป็น ใบประเทศ จะต้องเป็นใบประเทศทันที
  • หากตกลงกับสภาว่าจะเปลี่ยนใบเป็นค่าปรับ ทางนายกจะไม่รับเรื่องจากทั้ง 2 แก๊ง
ADMIN CASE

เรื่องที่แอดมินรับพิจารณา

  • ยกเว้นกรณี MG / ตัวปิง / ตัวแปลก / สตรีมสไนป์ / โปรแกรมช่วยเล่น / MULTI ID
  • นอกเหนือจากนี้แอดมินจะไม่รับเรื่องเด็ดขาด ให้ส่งไปที่สภาแทน
  • เงื่อนไขนี้ใช้เฉพาะ สตอรี่ที่เกิดขึ้นจากสภา
