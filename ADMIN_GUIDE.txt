วิธีให้แอดมินแก้ไขกฎเว็บไซต์

แบบที่ 1: แก้ผ่าน GitHub Pages

1. เอาโฟลเดอร์เว็บขึ้น GitHub repo
   - เปิด GitHub Pages ให้ชี้ไปที่ branch ที่ใช้ลงเว็บ เช่น main
   - เข้าเว็บแล้วเปิดหน้า admin.html เช่น
     https://ชื่อผู้ใช้.github.io/ชื่อ-repo/admin.html

2. ให้แอดมินสร้าง GitHub token ของตัวเอง
   - ไปที่ GitHub > Settings > Developer settings > Personal access tokens
   - แนะนำใช้ Fine-grained token
   - เลือก repo ของเว็บนี้
   - ให้สิทธิ์ Contents: Read and write
   - ไม่ควรแชร์ token ให้คนอื่น

3. ในหน้า admin.html
   - กรอก Owner เช่น ชื่อผู้ใช้หรือองค์กร
   - กรอก Repository
   - กรอก Branch เช่น main
   - วาง Token
   - กด "เชื่อม GitHub"

4. เลือกหน้ากฎที่ต้องการแก้
   - แก้หัวข้อใหญ่ คำอธิบาย หมวดกฎ และรายการกฎได้
   - กด "เพิ่มหมวด" หรือ "เพิ่มข้อกฎ" ได้ตามต้องการ
   - กด "บันทึกไฟล์" เพื่อ commit กลับเข้า GitHub repo
   - GitHub Pages จะอัปเดตเว็บหลังจาก GitHub deploy เสร็จ

แบบที่ 2: แก้ในเครื่อง

1. เปิดเว็บด้วย local server
   - ในโฟลเดอร์ webrules รันคำสั่ง:
     python -m http.server 8088 --bind 127.0.0.1
   - เปิด Chrome หรือ Edge ไปที่:
     http://127.0.0.1:8088/admin.html

2. กด "เลือกโฟลเดอร์เว็บ"
   - เลือกโฟลเดอร์ C:\Users\mon\Downloads\webrules
   - Browser จะขอสิทธิ์อ่าน/เขียนไฟล์ ให้กด Allow

3. เลือกหน้ากฎที่ต้องการแก้
   - แก้หัวข้อใหญ่ คำอธิบาย หมวดกฎ และรายการกฎได้
   - กด "เพิ่มหมวด" หรือ "เพิ่มข้อกฎ" ได้ตามต้องการ

4. กด "ดูตัวอย่าง" เพื่อตรวจหน้า
   - ถ้าถูกต้องแล้วกด "บันทึกไฟล์"
   - ระบบจะเขียนทับไฟล์ HTML หน้านั้นในโฟลเดอร์ทันที

หมายเหตุ
- ระบบนี้เป็นเครื่องมือแก้ไฟล์ static HTML ไม่ใช่ระบบ login จริง
- ถ้าใช้ GitHub mode สิทธิ์แก้ไขขึ้นอยู่กับ token ของแอดมิน
- ควรให้สิทธิ์ token เฉพาะ repo นี้เท่านั้น
- ถ้าเปิด admin.html โดยไม่เลือกโฟลเดอร์หรือไม่เชื่อม GitHub ระบบจะดาวน์โหลดไฟล์ HTML ที่แก้แล้วแทนการบันทึกทับ
